# 房地产行业政策与销售数据跟踪分析看板（2026）

> 一个用于实时跟踪和分析中国房地产行业**最新政策**与**销售开发情况**的纯静态数据可视化看板。
> 覆盖 2026 年开年至今的国家级政策时间线、核心关键词词云，以及销售/投资/开工/资金/房价等核心指标的同比环比可视化。

## 📖 项目简介

本项目面向房地产行业研究者、从业者及关注行业动态的用户，将分散在政府官网与权威媒体的政策信息与统计数据进行聚合、结构化与可视化呈现，帮助用户快速把握行业政策脉络与基本面走势。

主要解决三个痛点：
1. **政策分散难追踪** —— 将全年国家级政策按时间线串联，并标注来源、机构、核心观点与前后对比。
2. **数据零散难对比** —— 将国家统计局月度数据整合为可视化图表与表格，自动计算同比 / 环比。
3. **关键词难以一眼把握** —— 提取政策核心关键词生成词云，直观呈现政策主题权重。

## ✨ 功能特性

### 一、政策跟踪与分析
- 🏛️ **政策时间线**：2026 年 1-8 月共 17 条国家级房地产政策，按发布时间正序排列
- 🏷️ **多维标注**：每条政策标注发布日期、发布机构、政策类别、官方来源链接
- 📝 **核心观点提取**：每条政策提炼 3-7 条核心要点
- 🔍 **前后对比分析**：每条政策与之前政策的差异点与延续性分析
- 🎯 **类别筛选**：支持按"顶层定调 / 城市更新 / 房贷融资 / 住房公积金 / 存量收储 / 综合政策包"等类别筛选
- ☁️ **关键词词云**：基于全部政策关键词加权可视化，支持悬停查看权重

### 二、销售与开发数据可视化
- 📌 **核心指标概览**：6 张指标卡展示投资 / 销售 / 开工 / 资金 / 房企销售等关键数据与同比
- 📈 **8 类可视化图表**（基于 ECharts）：
  - 房地产开发投资完成额（累计同比）
  - 新建商品房销售面积与销售额（累计同比）
  - 新建商品房单月销售面积与环比增速（由累计值差分计算）
  - 商品房待售面积（期末值）
  - 新开工 / 竣工 / 施工（累计同比）
  - 房企到位资金结构（堆叠图 + 总额趋势）
  - 70 城商品住宅价格环比变动（分一二三线城市 · 新房 + 二手）
  - 2026 上半年 TOP10 房企销售额排行
- 📋 **数据明细表格**：开发投资 / 商品房销售 / 开工竣工 / 到位资金 四类表格，含同比与环比切换

### 三、文档
- 📄 README.md：项目说明
- 📄 CHANGELOG.md：版本更新记录

## 🚀 快速开始

### 方式一：直接打开
双击 `index.html` 即可在浏览器中查看（需联网加载 ECharts 与 wordcloud2.js 的 CDN 资源）。

### 方式二：本地服务器（推荐）
避免部分浏览器对 `file://` 协议的限制，建议起一个本地静态服务：

```bash
# Python
py -m http.server 8765
# 或 python3 -m http.server 8765

# Node.js
npx serve .
```

然后浏览器访问 `http://localhost:8765/index.html`。

## 🔄 数据更新指南

数据与视图完全分离，更新数据无需改动渲染逻辑：

### 方式一：手动更新

1. **新增政策**：在 `js/data/policies.js` 的 `window.POLICIES` 数组中追加一个政策对象（字段：`date` / `name` / `agency` / `category` / `url` / `points` / `comparison` / `keywords`）。
2. **更新销售数据**：在 `js/data/sales.js` 的 `window.SALES_DATA` 各数组中追加新一期累计值与同比；单月与环比由 `deriveMonthly` / `calcMoM` 自动计算。
3. **更新关键词**：在 `js/data/keywords.js` 的 `window.KEYWORDS` 中调整权重或新增关键词，并把新政策 id 关联到对应关键词的 `policies` 数组。
4. 刷新页面即可看到最新数据。

### 方式二：自动抓取统计局数据（推荐）

项目内置 `scripts/fetch_real_estate_data.py`，可自动从国家统计局官网抓取最新《全国房地产市场基本情况》月度报告：

```bash
# 依赖
pip install requests beautifulsoup4 lxml

# 运行（需在国家统计局发布月度数据后，通常为月中）
py scripts/fetch_real_estate_data.py
```

**脚本输出**：
- `scripts/sales_data_snippet.txt` —— 可粘贴到 `sales.js` 的累计值代码片段
- `scripts/fetched_data.json` —— 原始抓取数据（含开发投资、销售、待售、资金、开工竣工等）
- `scripts/debug_report_text.txt` —— 抓取页面的原始文本（用于调试正则）

**更新流程**：
1. 脚本抓取到 1-N 月累计值后，计算单月值 = 本期累计 - 上期累计
2. 将单月值自动追加到 `sales.js` 对应数组（`investment.total` / `sales.area` 等），同时追加环比到各 `mom` 子块
3. 脚本接着自动抓取《70个大中城市商品住宅销售价格变动情况》报告，解析表1/表2原始城市环比指数，按国家统计局标准一二三线城市划分计算加权平均与上涨城市数，追加到 `price70.months` / `newHouse` / `secondHand` 各数组
4. 脚本自动更新 `periods`、`meta.updated`、`meta.note`，并保存累计数据到 `scripts/cumulative_history.json` 供下次差分使用
5. 若历史中缺少上月累计数据，脚本会自动跨页抓取上月报告补全
6. 房企 TOP10 销售数据需手动从中指研究院、克而瑞获取后填入 `developers.top10`

> **提示**：脚本依赖国家统计局页面 HTML 结构，若官网改版导致正则失效，可参考 `debug_report_text.txt` 调整 `parse_stats_bureau_report` 中的 patterns。
